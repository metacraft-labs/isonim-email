# isonim-email — agent guide

`isonim-email` is an IsoNim add-on library for authoring HTML email. It is in
the design stage.

- The design specification and the milestone plan are maintained outside this
  repository. In a Metacraft workspace, the workspace's project index names
  them; read both before starting work — the milestone plan says which
  milestone is current.
- The framework source is the sibling checkout `../isonim`. The closest
  precedent for an add-on library's layout, build and tests is
  `../isonim-docs`.
- This repository is **public**. Commit messages and files must be
  user-facing: never describe private roadmap, internal spec mechanics, or
  cite private repositories.
- Branch model: product repository — mainline `dev`, agent landing branch
  `agents`.
